# ChatLayout

The chat widget scaffold: a card-framed column with an optional header
(avatar, name, status), a scrollable message area and a composer pinned at the
bottom. Message state, auto-scroll and sending stay in the app/widget.

<Canvas of={ChatLayoutStories.Widget} />

## Slots & props

| Slot / prop | Type | Required | Content |
|---|---|---|---|
| `header` | `ReactNode` | — | Widget header: `Avatar` (with `online`), name, status. |
| `children` | `ReactNode` | ✅ | The conversation — `<ChatBubble>`s, stacked vertically (`gap` = `stack-sm`). |
| `composer` | `ReactNode` | — | Input row: `Textarea variant="inline"` + a send `Button` (`aria-label`!). |

<Controls />

## Responsive behavior

- Fills the height of the **parent container** (`h-full`) — the embedding
  context decides the widget size (see the story: an `h-96` frame).
- Only the message area scrolls; header and composer stay put
  (`overflow-y-auto` in the middle, `shrink-0` on the outside).

## Do's & don'ts

- ✅ Give the embedding element a fixed height — without a height there is no
  scrolling conversation.
- ✅ Pass messages as `<ChatBubble from="user|assistant">`.
- ❌ Don't rebuild scroll handling in the conversation; auto-scroll belongs in
  the app (a ref on the end of the list), not in the template.
- ❌ Never shrink or squeeze composer buttons — use an icon button with an
  `aria-label` (guidelines rule 5).
