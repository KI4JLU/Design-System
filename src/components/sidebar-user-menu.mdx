# SidebarUserMenu

The user menu in the sidebar footer: an initials avatar, the name above the
role, a chevron — the whole row is the trigger of a `DropdownMenu`. Replaces
the block every app had built itself in its sidebar footer. Name and role are
truncated, so long values never widen the 256px column.

## Division of work

The component owns the **trigger and the menu frame**; the items are
`children` (`DropdownMenuItem`s) and belong to the app — with its actions and
its routing. A link becomes a menu item with `asChild` (see
"TruncatesLongValues").

```tsx
<SidebarUserMenu initials="JL" name="Jamie Lee" role="Admin">
  <DropdownMenuItem onSelect={() => setSettingsOpen(true)}>
    <Settings width="1em" height="1em" aria-hidden />
    Einstellungen
  </DropdownMenuItem>
  <DropdownMenuSeparator />
  <DropdownMenuItem variant="destructive" onSelect={signOut}>
    <LogOut width="1em" height="1em" aria-hidden />
    Abmelden
  </DropdownMenuItem>
</SidebarUserMenu>
```

| Prop | Type | Meaning |
|---|---|---|
| `initials` | `string` | 1–2 characters for the avatar, e.g. "JL". |
| `name` | `ReactNode` | Display name, the emphasized first line. |
| `role` | `ReactNode` | Second line (role, email, tenant …); optional. |
| `children` | `ReactNode` | The menu items. |

## "Einstellungen" opens the SettingsDialog

The "Einstellungen" item sets the `open` state of a controlled
`SettingsDialog` via `onSelect`; its "Darstellung" section is
`AppearanceSettings` (color scheme, contrast, accent color, style). In this
story it is bound to the real providers of the Storybook decorator — a choice
in the dialog switches the whole canvas. Details and the known focus gap after
closing: Storybook "Components/Overlays/SettingsDialog" → Docs.

## Collapsed

In a collapsed sidebar the trigger shrinks to the avatar alone (round, icon
size, no chevron). The menu is **kept**, not hidden: it is the only way to
sign out, and a control that disappears on collapsing would make collapsing
lossy. Name and role stay in the DOM as `sr-only`, so the trigger's accessible
name is **the same string** in both states.

The trigger is a row like the `SidebarCard`s above it: the same row radius
(`--ui-radius-row`), the same inset.
